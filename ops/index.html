HOW TO READ THIS PAGE
Up to date means two things at once: that the dashboard was rebuilt, and that what the link opens is exactly what was built. A stale dashboard that looks just like a fresh one is worse than one that is down, because people believe it.

The date of the data is not the date of the file. Every dashboard declares which day its figures are from; the file can be touched without the figures changing.

The links are permanent. Always the same, and they update themselves.

ERP migration

Documentation dashboard for the migration workstream  ·  updated by hand

WHY THIS ONE HAS NO FRESHNESS LIGHT

The other five dashboards are rebuilt by a job every night, so if one goes stale that is a failure and somebody has to hear about it. This one is written by hand, whenever the workstream has news. Applying the same rule would paint it red almost every day, and an alarm that always goes off stops being an alarm: people learn to ignore it, and the day it is real they will not look either.

What is still checked is the other thing: that the published copy matches the local one. That does not depend on how often it is rebuilt, and it is exactly the mistake that can happen when somebody rebuilds something by hand.
